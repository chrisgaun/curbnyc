# CurbNYC development

- Run `npm test` and serve the repository root with `python3 -m http.server 8000`.
- Trace the active entry point from `index.html`. Older meter scripts and `meters-baseline.html` are regression references.
- Keep official meter blockfaces and their fallback independent of background geometry. Preserve conservative schedule results for unknown or ambiguous data.
- Measure performance changes on a documented route. Record device, browser, data source, and whether caches were cold or warm.
- Confirm the deployed build before reporting publication. Preserve approved release tags and use an owner-reviewed PR for changes.
